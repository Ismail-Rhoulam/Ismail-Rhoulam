# Ismail Rhoulam

PhD student in Marketing Science at Mohammed V University in Rabat (LARMODADD, FSJES Souissi).

My research is on **experiment-calibrated marketing measurement**. Marketing mix models are cheap to run but easy to fool; randomized experiments are reliable but narrow and expensive. I work on combining the two, so that budget decisions rest on causal evidence.

## Research questions

**Transportability.** A lift test ran in one market, in one quarter. When does its result hold for the market and period where the budget is actually being decided, and how should it be adjusted when it doesn't?

**Adaptive experimentation.** How can an experiment shift its allocation as data comes in, so it answers the question the decision depends on sooner and at lower cost?

**Risk-aware budget allocation.** Effect estimates come with uncertainty. How should a budget account for the downside instead of optimizing expected return alone?
